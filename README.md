# Flappy — лендинг

Промо-страница игры Flappy. Один статический HTML-файл, без сборки, без внешних
библиотек, шрифтов и CDN. Все изображения лежат рядом в `img/`.

## Что внутри

```
site/
├─ index.html      вся страница: разметка, стили и ~30 строк JS
├─ img/
│  ├─ screen-day.png      игровой экран, день (288×512)
│  ├─ screen-sunset.png   игровой экран, закат
│  ├─ screen-night.png    игровой экран, ночь
│  ├─ og.png              превью для соцсетей (1200×630)
│  ├─ icon-128.png        favicon
│  └─ icon-512.png        apple-touch-icon
├─ flappy-tilda.html      версия одним файлом для Tilda (T123)
└─ README.md
```

## Публикация

Сайт уже опубликован через GitHub Pages:

**https://sanyazheltyshev4-dev.github.io/flappy-site/**

Обновление: закоммитить изменения в ветку `main` — Pages пересоберётся сам
за минуту-две.

## Ссылки на файлы игры

Кнопки скачивания ведут на релиз `v1.0.0` этого же репозитория
(`releases/latest/download/Flappy.apk` и т. д.), поэтому страницу можно
переносить куда угодно, не ломая ссылки. Сами файлы в git не хранятся —
только как ассеты релиза.

## Tilda

`flappy-tilda.html` — тот же дизайн в виде одного HTML-блока: картинки
зашиты в base64, стили обёрнуты в `@scope (.fl-root)`, чтобы не влиять на
остальную страницу Tilda.

Порядок:

1. В Tilda добавить блок **T123 «HTML-код»** (нужен платный тариф или
   активный пробный период).
2. Открыть `flappy-tilda.html`, скопировать всё содержимое.
3. Вставить в блок, сохранить, опубликовать.

Если нужен другой адрес для скачивания — поменять ссылки в конце
`flappy-tilda.html` (они такие же, как в `index.html`).

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для проверки в мобильном
масштабе — режим устройства в DevTools или просто сузить окно.
